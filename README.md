\# Kaleo — Called. Connected.



A lightweight voice and video calling app built with HTML, CSS, JavaScript, and Node.js.



\## Features



\- 1:1 voice and video calls (WebRTC)

\- Minimal data usage (AV1/VP9 preferred, 360p default)

\- Low-latency signaling (Socket.IO)

\- Kaleo branding with custom logo



\## Tech Stack



\- Frontend: HTML + CSS + Vanilla JS

\- Backend: Node.js + Express + Socket.IO

\- Media: WebRTC (STUN + TURN)



\## Run Locally



&#x20;   npm install

&#x20;   npm start



Then open http://localhost:5174 in two browser windows.



\## Deploy



Ready for Render, Railway, or Fly.io.
